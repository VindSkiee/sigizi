# SIGIZI - Portal Publik

Next.js application for public batch tracking and complaints.

## Setup

```bash
# Install dependencies
pnpm install

# Start development
pnpm dev
```

## Available Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm start` - Start production server
- `pnpm lint` - Run ESLint

## Pages

- `/` - Home page with batch search
- `/batch?number=XXX` - Batch tracking page (SSR)
