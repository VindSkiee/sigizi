**Lokasi:** Admin Order Management (`/admin/suppliers`)
**Kondisi:** Order dengan status DELIVERED → klik "Selesai" → tidak terjadi apa-apa

### Penyebab

Backend `order.service.ts` baris 385-388 memiliki validasi yang MEMAKSA upload bukti pembayaran saat transisi ke COMPLETED:

```typescript
// apps/backend/src/modules/order/services/order.service.ts
// Line 385-388
if (newStatus === OS.COMPLETED && !dto.paymentEvidenceUrl) {
  throw new BadRequestException(
    "Bukti pembayaran wajib diunggah saat menyelesaikan order",

}
```

